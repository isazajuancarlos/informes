# firma, y la licencia no se puede verificar. Nada se bloquea.
#
#   pip install -r requirements-firma.txt
#
# ============================================================================
# NO SE INSTALA DESDE PyPI, Y ES DELIBERADO
# ============================================================================
#
# `--no-index` corta el índice público a propósito. Si el cliente obtuviera
# `quipu-crypto` de PyPI lo obtendría **bajo AGPL-3.0**, y su uso en red del
# conjunto activaría el artículo 13: quedaría obligado a ofrecer el código
# fuente del sistema completo a quien interactúe con él por red. Un cliente
# corporativo con asesoría competente lo detecta en la debida diligencia.
#
# La Cláusula 9.2 del EULA entrega esa copia bajo licencia comercial —para eso
# existe la doble licencia— y la 9.3 le prohíbe sustituirla por la pública.
# Estas dos banderas son la mitad TÉCNICA de esas cláusulas.
#
# Poblar vendor/ antes de empaquetar:
#
#   python preparar_distribucion.py
#
# Si vendor/ está vacío, esta instalación FALLA en vez de caer a PyPI. Es lo
# correcto: fallar ruidosamente al empaquetar es barato; descubrir en una
# auditoría que el cliente instaló la copia AGPL, no.
# ============================================================================

--find-links vendor/
